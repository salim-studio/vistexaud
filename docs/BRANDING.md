# vistexaud — Brand Guide

**vistexaud = VIS**ion + **TEX**t + **AUD**io. One fast pipeline for live images, text, and sound.

## Logo

- Mark: hexagon + `VXA` monogram + `VIS TEX AUD` wordmark (`docs/assets/logo.svg`).
- Dark tile `#0B1020` with a violet → cyan → amber gradient stroke.
- Three dots = the three modalities: Vision `#7C3AED`, Text `#06B6D4`, Audio `#F59E0B`.
- Minimum size: 32 px. Keep clear space equal to the hexagon stroke width.

## Palette

| Token   | Hex       | Usage                        |
|---------|-----------|------------------------------|
| Void    | `#0B1020` | Logo tile, hero backgrounds  |
| Vision  | `#7C3AED` | Vision tasks, primary accent |
| Signal  | `#06B6D4` | Text tasks, links, highlights|
| Pulse   | `#F59E0B` | Audio tasks, warnings, energy|
| Paper   | `#F8FAFC` | Light backgrounds            |
| Ink     | `#0F172A` | Body text on light           |

## Typography

- Display / logo: Segoe UI, Arial, sans-serif — ExtraBold, letter-spaced.
- Body / docs: system sans stack. Code: Consolas / Menlo monospace.

## Voice

- English only. Short sentences. Practical over academic.
- Name usage: lowercase `vistexaud` in prose and code; `VXA` only inside the mark.
